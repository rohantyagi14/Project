
# 🎙️ Python Voice Assistant

A simple Python Voice Assistant that listens to voice commands and performs basic tasks such as telling the time, opening websites, telling jokes, playing music, and converting text into a handwriting image.

## 🚀 Features

* 🎤 Speech Recognition
* 🔊 Text-to-Speech
* ⏰ Tell Current Time
* 🌐 Open YouTube
* 🌍 Open Website
* 😂 Tell Random Jokes
* 🎵 Play Local Music
* ✍️ Convert Text to Handwriting Image
* 🚪 Exit with Voice Command

## 🛠️ Technologies Used

* Python 3
* SpeechRecognition
* pyttsx3
* pywhatkit
* pyjokes

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/python-voice-assistant.git
```

2. Go to the project folder

```bash
cd python-voice-assistant
```

3. Install the required libraries

```bash
pip install SpeechRecognition pyttsx3 pywhatkit pyjokes PyAudio
```

4. Run the project

```bash
python main.py
```
